
# Ideas

**By: Rein Alderfer**

1. What is my final project? I want to deploy a proxmox cluster. The cluster will run two Proxmox Servers and two Proxmox Backup Servers. This is for redundancy. One reduntant server per active Proxmox server. Although this may not be efficient. 
2. What will this be used for? Proxmox is a type one hypervisor that has many features that are very usefull for optimally running services on multiple different virtual machines or LXC containers. The Virtual machines I want to run is ubuntu server, with room to add different linux server distros.
3. What programs will I run on these vm's? I want to run anything from a local git repository, webservers using apache, to a NAS, and docker constainers running things such as a cloudflare tunnel and anything else.
4. Long term plan, make this accesible to students in the future with documentation so in the future they can access the proxmox cluster and deploy services and programs they would like to use under the supervision of professor Reddig.
