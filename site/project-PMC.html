Project PMC – Computer Cluster with Hypervisor

This project by Rein Alderfer involves building a small-scale computer cluster using multiple machines and deploying a hypervisor to manage virtual machines.

Objectives

  • Install and configure a hypervisor
  • Create and manage virtual machines
  • Demonstrate resource sharing

Outcome

Students demonstrate virtualization, scalability, and system management skills.
