Project B – Make Frankenstein Live and have Value

This project involves Dr Leap's previous 2011 Linux Server that did not turn on at all during initial testing. The computer now turns on and appears to be running an older Linux OS. It has been decided that the server will be repurposed to run a wireshark instance to monitor network traffic within the networking lab.

Objectives

  • Bring it back to life
  • Install friendlier operating system
  • Install wireshark
  • Connect server to primary switch or router and log traffic

Process

  1. Fixing outstanding issues with server
    The CMOS battery on the motherboard had died, causing any changes made in the BIOS such as boot order to not be saved, while this was not crucial, repair would would streamline later use.
  2. Installing a friendlier OS
    Due to the system being relatively outdated, external boots can only happen either over a NIC or a CD disk using the reader. The simplist option was to burn a linux distro onto a CD or DVD drive. This step proved to be more complicated than anticipated, as many versions either did not fit onto a CD or DVD, or did not support such old hardware. An older version of Ubuntu Lite was found to be compatible with the hardware and also fit onto a DVD.
  3. Installing Wireshark
    After installing the OS and necessary packages, Wireshark could be installed using the apt package manager. This was a relatively straight forward process. However, some permission changes were needed to allow user to run wireshark without root access each time.

Outcome

The server is now able to successfully boot into a linux OS and is able to run Wireshark. However, due to the low hardware specifications, the functions of the server may be limited. It has yet to be connected to a switch or router to log traffic, but doing so should be relatively easy to complete, with simple setup required on the switch or router to mirror traffic to server.
