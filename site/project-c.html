Project C – Build a PC and Demo RAID 10

This project involves building PC and Demoing RAID 10 on 4 drives with existing Windows Software.

Objectives

  • Install hardware items and bring a PC to life
  • Set up RAID 10
  • Demonstrate the features of RAID

Outcome

Students demonstrate budgeting of parts, hardware installation skills, software configuration, and backup management skills.
